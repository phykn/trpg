# 프롤로그

**챕터 1([10-first-story.md](10-first-story.md)) 앞의 짧은 이야기**의 설계다. 김봉식이 왜 쫄쫄이 타이츠에 챔피언 벨트를 차고 이세계 숲길에 떨어졌는지를 잇는다. 동시에 처음 하는 사람이 장치를 하나씩 만나게 한다. 사람들의 말이 다음 할 일을 넌지시 가리키고, 처음 만나는 장치는 DM이 일러 준다(07 2절). 폴더는 `scenarios/arena/`다.

**이 문서는 진실을 모두 적는다. 해 볼 사람은 읽지 않는다.**

## 한눈에

- 제목: **프롤로그: 사라진 벨트**
- 현실의 체육관. 아홉 시 타이틀 방어전을 앞두고 김봉식의 챔피언 벨트가 대기실에서 사라진다.
- 사람 셋, 곳 셋, 막힘 셋(거짓말, 꺼림, 잠김 하나씩), 번진 일 하나. 한 판 10칸. 한 칸은 십이 분, 저녁 일곱 시에 시작해 아홉 시 공으로 끝난다.
- 어느 결말이든 김봉식은 벨트를 찬 채 경기를 마치고 뒷골목에서 트럭에 치인다. 챕터 1의 도입이 거기서 잇는다.

## 1. 진실

| 물음 | 진실 |
|---|---|
| **누가** | 매니저 최두식 |
| **어떻게** | *링 밑 트렁크* |
| **왜** | *도난 소동* |

**전말**: 최두식은 텅 빈 객석을 채우려고 벨트 도난 소동을 꾸몄다. 6시 10분에 매표소 노트북으로 보도자료를 미리 써 두고, 6시 반 김봉식이 편의점에 간 사이 열쇠로 케이스를 열어 벨트를 링 밑 소품 트렁크에 잠갔다. 그동안 매표소는 비어 있었다.

**겉 이야기**: 벨트를 노리는 도전자 강태오가 열린 창문으로 들어와 가져갔다.

**시각표**

| 때 | 최두식 | 강태오 | 윤소라 |
|---|---|---|---|
| 6시 10분 | 매표소에서 보도자료를 쓴다 | 링에서 몸을 푼다 | |
| 6시 반 | 대기실에서 벨트를 꺼내 나온다. 링 밑 트렁크에 잠근다 | 대기실 앞을 지나다 그를 본다 | 조명을 보다 트렁크를 잠그는 그를 본다 |
| 6시 45분 | | | 매표소 셔터가 내려진 것을 보고 표를 팔기 시작한다 |
| 7시 (판 시작) | 대기실에서 김봉식에게 소리친다 | 링에 있다 | 매표소에 있다 |

## 2. 반전

| 단계 | 플레이어가 믿는 것 | 뒤집는 것 | 수(09 3절) |
|---|---|---|---|
| 시작 | 매니저 말대로 도전자가 훔쳤다 | 강태오는 링에서 가져가겠다고 한다. 그가 본 것은 대기실에서 나오는 최 실장이다 | 모두에게 비밀이 있다 |
| 진실 | 함께 벨트를 찾는 매니저는 범인이 아니다 | "매표소에 있었다"가 깨지고, 보도자료의 저장 시각이 도난보다 이르다 | 범인은 가장 먼 사람, 시각이 틀렸다 |

## 3. 사실

| 이름 | 사실 |
|---|---|
| *매표소를 비운 매니저* | 최두식은 6시 반 무렵 매표소에 없었다 |
| *링 밑 트렁크* | 벨트는 링 밑 소품 트렁크에 잠겨 있었다 |
| *도난 소동* | 최두식은 벨트 도난 소동으로 오늘 경기를 기사에 띄우려 했다 |

## 4. 곳과 볼 것

대기실(시작) — 경기장 — 매표소.

| 곳 | 볼 것 | 보여 주는 사실 |
|---|---|---|
| **대기실** | 열린 채 비어 있는 벨트 케이스, 긁힌 자국 없는 자물쇠 | 없다 |
| | 한 뼘 열린 창문 | 없다 (헛다리) |
| | 쇠 구둣주걱 (물건. 납작하고 단단하다) | |
| **경기장** | 링 밑 소품 트렁크 (**잠김**) | |
| | └ 안: 소품 깃발 밑의 챔피언 벨트 | *링 밑 트렁크* |
| **매표소** | 노트북의 보도자료 "[단독] 챔피언 벨트 도난!", 저장 시각 6시 10분 | *도난 소동* |
| | 일자 드라이버 (물건. 납작하고 단단하다) | |

- 소품 트렁크 — 약점: 납작하고 단단하다. 주인: 최두식. 단단하다. 실마리: "걸쇠 틈이 벌어져 있다. 납작한 쇠붙이를 끼우면 젖혀지겠다."

## 5. 사람

### 최두식 — 매니저 (대기실)

| 화제 | 자세 | 할 말 | 보여 주는 사실 | 알리는 것 |
|---|---|---|---|---|
| 벨트 | 숨기지 않는다 | 벨트는 6시까지 케이스에 있었다. 링에 있는 강태오가 제일 수상하다 | | 강태오, 경기장 |
| 그 시각 | **거짓말한다** | 거짓말: 6시 반부터 7시까지 나는 매표소에서 표를 팔았다. 깨진 뒤: 매표소에는 없었다. 기자한테 벨트가 없어졌다고 미리 귀띔해 뒀다, 기사가 나면 표가 팔리니까 | 깨진 뒤: *도난 소동* | |
| 오늘 경기 | 숨기지 않는다 | 아홉 시 공이 울리면 경기는 그대로 간다. 벨트 없이 링에 오르면 챔피언 체면이 말이 아니다 | | |

- 그 시각 — 깨는 사실: *매표소를 비운 매니저*

### 강태오 — 도전자 (경기장)

처음 태도: 믿음 낮음.

| 화제 | 자세 | 할 말 | 보여 주는 사실 | 알리는 것 |
|---|---|---|---|---|
| 벨트 | 숨기지 않는다 | 그 벨트는 오늘 밤 링 위에서 내가 가져간다. 어제 SNS에도 그렇게 썼다 | 없다 (헛다리) | |
| 아까 본 것 | 숨기지 않는다 | 6시 반쯤 대기실 앞을 지나는데 최 실장이 안에서 나오더라 | *매표소를 비운 매니저* | 최두식, 대기실 |

### 윤소라 — 막내 직원 (매표소)

| 화제 | 자세 | 할 말 | 보여 주는 사실 | 알리는 것 |
|---|---|---|---|---|
| 매표소 | 숨기지 않는다 | 6시 45분에 와 보니 매표소 셔터가 내려져 있었다. 그 뒤로는 내가 혼자 표를 팔았다 | *매표소를 비운 매니저* | |
| 소품 | **꺼린다** | 풀린 뒤: 6시 반쯤 조명을 보다가, 실장님이 링 밑 소품 트렁크에 뭘 넣고 잠그는 걸 봤다 | *링 밑 트렁크* | 최두식 |

- 소품 — 바라는 것: *매표소를 비운 매니저*. 실마리: "실장님이 정말 내내 매표소에 계셨다면, 저는 할 말이 없어요."

## 6. 장치를 만나는 차례

| 차례 | 장치 | 무엇이 이끄는가 |
|---|---|---|
| 1 | 둘러보기, 묻기, 수첩 | 빈 수첩으로 시작한다. DM이 대기실을 둘러보거나 곁의 최 실장에게 물어보라고 권한다. 둘러보면 빈 케이스와 창문, 구둣주걱이 적힌다 |
| 2 | 옮기기 | 최 실장이 경기장의 강태오를 가리킨다 |
| 3 | 거짓말 | 강태오의 "대기실에서 나오더라"가 최 실장의 "매표소에 있었다"와 어긋난다. 윤소라의 "셔터가 내려져 있었다"도 어긋난다 |
| 4 | 꺼림 | 윤소라의 실마리가 무엇을 내밀지 가리킨다 |
| 5 | 잠김과 주사위 | 트렁크의 실마리가 납작한 쇠붙이를 가리킨다. 대기실과 매표소에 하나씩 있다 |
| 6 | 번진 일 | 3칸째에 통화하는 목소리가 들리고, 6칸째에 보도자료가 지워진다 |
| 7 | 결론 | 아홉 시 공 |

## 7. 번진 일

| 때 | 일 | 막는 조건 | 조짐 |
|---|---|---|---|
| 6칸째 | 최두식이 보도자료를 지운다 | 최두식의 거짓말을 깼다 | 복도에서 최 실장이 누군가와 통화하는 목소리가 들린다 |

- 지워져도 *도난 소동*은 최두식의 깨진 뒤 말로 얻을 수 있다.

## 8. 결말

| 결말 | 대목 |
|---|---|
| 다 밝혔다 | 링 밑에서 꺼낸 벨트를 치켜들고 보도자료를 관객 앞에 내놓는다 |
| 누구인지는 밝혔다 | 최 실장이 너스레를 떨며 링 밑에서 벨트를 꺼내 온다 |
| 엉뚱한 사람을 짚었다 | 짚은 사람이 자리를 뜨고, 최 실장이 "찾았다!" 하며 벨트를 들고 온다 |
| 밝히지 못했다 | 최 실장이 "찾았다!" 하며 벨트를 들고 온다. 기사는 그의 뜻대로 난다 |

**진실 풀이**는 전말 뒤에 챕터 1로 넘어가는 장면으로 끝난다. 경기를 마친 김봉식이 쫄쫄이 타이츠에 벨트를 찬 채 뒷문을 나서고, 골목 끝에서 트럭의 헤드라이트가 쏟아진다.

## 9. 주사위 없이 가는 길

1. 대기실: 최 실장에게 벨트와 그 시각을 묻는다.
2. 경기장: 강태오에게 아까 본 것을 묻는다.
3. 매표소: 보도자료를 본다. 윤소라에게 강태오의 말을 내밀어 꺼림을 푼다. 링 밑 트렁크.
4. 결론: 최두식 / 윤소라의 말 / 보도자료.

옮기기 두 칸.

## 10. 이 이야기로 볼 것

- 처음 하는 사람이 설명 없이 묻기, 옮기기, 내밀기, 물건 쓰기를 해 보게 되는가.
- 강태오를 먼저 의심하는가. 최 실장 쪽으로 눈이 가는 때는 언제인가.
- 끝의 트럭 장면이 챕터 1의 도입으로 자연스럽게 이어지는가.
- 15분 안팎에 끝나는가.
