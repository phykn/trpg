# 재미 이론

재미는 증명할 수 없습니다. 이 문서는 재미를 요소로 나누고, 각 요소의 **전제**는 [rule.md](rule.md)와 [engine.md](engine.md)의 정리로 보장하며, 그 전제가 실제로 재미가 되는지는 **기록 위의 측정**과 **가설**로 다룹니다. **새 공리는 없고**, 측정은 `R`, `K`, 프롬프트에 들어가지 않습니다(온톨로지 공리 2, 5). 엔진의 품질 기준 Q6이 이 문서입니다.

```
재미의 요소 (2절)
  ├ 규칙이 보장하는 전제 (3절)   ← 정리로 성립, 다시 재지 않음
  ├ 굴림과 시간의 계산 (4절)      ← 규칙에서 바로 나오는 수
  └ 측정과 가설 (5~6절)          ← 실제 플레이로만 확인
```

## 1. 목적

| 바라는 것 | 자리 |
|---|---|
| 재미를 무엇으로 이루어졌는지 말할 수 있다 | 2절 요소 |
| 규칙만으로 지켜지는 것과 재봐야 하는 것을 가른다 | 3절 전제, 5절 측정 |
| 원고와 규칙의 수를 정하기 전에 결과의 분포를 안다 | 4절 계산 |
| 재미가 떨어진 곳을 찾아 한 곳만 고친다 | 5절 고칠 곳, 6절 판단 |

## 2. 요소

| 요소 | 뜻 | 기대는 장치 |
|---|---|---|
| **주체성** | 플레이어가 쓴 문장이 그 뜻대로 행동이 되고, 그 행동이 세계를 바꾼다 | 해석, 즉흥, 여러 해법 |
| **긴장** | 결과가 불확실하고, 걸린 것이 보인다 | 2d6, 위험, 위험 시계, 위협, 마감 |
| **결과** | 실패와 선택이 상황을 바꾸고, 그 변화가 뒤에 다시 쓰인다 | 대가, 복잡화, 갈림, 흉터, 이력 패턴 |
| **관계** | 인물이 플레이어가 한 일에 따라 다르게 대한다 | 신뢰와 두려움, 부탁, 약속, 유대 |
| **성장** | 주인공과 플레이어가 장마다 나아진다 | 성장, 기댄 것, 선언 |
| **리듬** | 긴장과 해소가 번갈아 오고, 이야기가 늘어지지 않고 끝난다 | 박자와 장면, 마감, 휴식 |

## 3. 규칙이 보장하는 전제

아래는 정리로 성립하므로 플레이에서 다시 재지 않습니다. 재는 것은 이것이 재미로 느껴지는가입니다.

| 요소 | 전제 | 근거 |
|---|---|---|
| 주체성 | 실행되는 것은 늘 후보이고, 모델이 확신하지 못하면 플레이어가 고르거나 아무것도 바뀌지 않음 | engine 정리 1, 3 |
| 주체성 | 어떤 문장도 작은 이득 이상을 얻지 못하므로, 말솜씨가 아니라 상황 판단이 결과를 가름 | rule 정리 4, engine 정리 4 |
| 긴장 | 확인 카드의 위험은 실행 때와 같고, 숨은 것이 위험을 바꾸지 않음 | rule 정리 5, engine 정리 6 |
| 결과 | 굴림은 늘 보이는 무언가를 바꾸고, 실패와 대가 있는 성공은 위험 시계를 바꿈 | rule 정리 6 |
| 관계 | 부탁의 약속은 늦어도 다음 장 전환에서 지킴이나 어김으로 끝남 | rule 정리 8 |
| 리듬 | 판정이 있는 행동마다 시간이 흐르고, 원고가 `fill`을 내리지 않은 위협은 `n · B`단계 안에 도착하거나 물러남 | rule 정리 7 |
| 리듬 | 어디에 와 있든 결말에 닿을 수 있음 | rule 정리 9 |

## 4. 굴림과 시간의 계산

### 4.1 결과의 분포

보정 합 `z = stat(p★, 방식) + 도움 − 방해`는 −1에서 4까지입니다(rule 3.1, 방식의 한도 `0…3`은 rule 7절).

| `z` | 성공 | 대가 있는 성공 | 실패 |
|---|---|---|---|
| −1 | 8.3% | 33.3% | 58.3% |
| 0 | 16.7% | 41.7% | 41.7% |
| 1 | 27.8% | 44.4% | 27.8% |
| 2 | 41.7% | 41.7% | 16.7% |
| 3 | 58.3% | 33.3% | 8.3% |
| 4 | 72.2% | 25.0% | 2.8% |

- `0 ≤ z ≤ 2`에서는 대가 있는 성공이 가장 흔합니다(`z = 0`은 실패와, `z = 2`는 성공과 같음). 이 규칙의 기본 결과는 "되지만 무언가를 치른다"이고, 이것이 결과와 긴장의 주된 원천입니다.
- 잘하는 방식(`z = 3, 4`)에서도 대가 없는 성공은 4분의 3을 넘지 않습니다. 그래서 성장해도 긴장이 남습니다.
- 기댄 것 하나(+1)는 실패를 약 11%포인트(`z`에 따라 6~17) 줄입니다. 그래서 상황을 읽고 기댈 것을 찾는 데 보상이 있습니다.

### 4.2 위험 시계의 리듬

굴림 한 번이 위험 시계에 더하는 기댓값은 `ρ = P(대가 있는 성공) + c · P(실패)`이고, `c`는 위험이 높음이면 2, 아니면 1입니다(rule 3.4). 칸 수 `n`인 시계는 평균 약 `n / ρ`번 굴리면 찹니다(높음은 넘칠 수 있어 하한, 선언의 +1은 뺌).

| `z` | `ρ` (낮음·보통) | `ρ` (높음) | `n = 4`일 때 굴림 수 (낮음·보통) |
|---|---|---|---|
| 0 | 0.83 | 1.25 | 약 4.8 |
| 1 | 0.72 | 1.00 | 약 5.5 |
| 2 | 0.58 | 0.75 | 약 6.9 |

원고는 이 표로 `n`을 정합니다. 장마다 위기를 한두 번 겪게 하려면 `n · (1~2) ≈ ρ ×` 그 장에서 기대하는 굴림 수입니다.

### 4.3 장의 길이

박자가 오르는 단계 `B`번 안에 장면이 끝나고, 칸 수 `n_마감`인 마감은 장면 `n_마감`개 안에 도착합니다(rule 정리 7, 9). 그래서 한 장은 박자가 오르는 단계 `n_마감 · B`번을 넘지 않습니다. 마감의 칸 수는 `칸` 종류의 상한 6 이하이므로, 장의 최대 길이는 원고가 `B`로 정합니다. 장의 길이가 `l`단계 이상일 수 있으려면 `B ≥ l / n_마감`이어야 합니다(F10의 40단계는 `n_마감 = 6`일 때 `B ≥ 7`).

## 5. 측정

모든 지표는 저장된 기록 `L`(사건의 `a`, `r`, `Δ`, `mods`)과 엔진의 턴 기록(engine 2.5의 `P`)에서 오프라인으로 계산하고, 설문만 플레이어에게 묻습니다. 설문의 답은 `S`, `L`, `P` 밖에 따로 둡니다. 플레이어가 마지막 요청 뒤 7일 동안 요청하지 않은 게임을 **그만둔 게임**으로 봅니다. 목표 범위는 처음 가설이며 6절의 절차로 고칩니다.

| | 지표 | 정의 | 처음 가설 | 어긋나면 고칠 곳 |
|---|---|---|---|---|
| F1 | 해석 수용 | 자유 문장 중 되묻기, 거절, `try(p★, ν₀)`로 끝나지 않은 비율 | 85% 이상 | 해석 규칙, 원고의 이름과 동의어 |
| F2 | 자유 문장 | 버튼이 아니라 문장으로 고른 단계의 비율 | 50% 이상 | 추천 버튼이 너무 좋음, 문장이 자주 거절됨 |
| F3 | 해법의 다양성 | 장애물마다 여러 플레이에서 쓰인 서로 다른 해법과 방식의 수 | 2 이상 | 원고의 해법과 어울림 |
| F4 | 굴림의 결과 | 굴림 중 대가 있는 성공과 실패의 비율 | 45~75% | 방식 값, 원고의 기본 위험 |
| F5 | 위기의 간격 | `τ_위험` 사이의 굴림 수 | 4~8 | 위험 시계의 칸 수(4.2) |
| F6 | 위협 반응 | 등장한 위협 중 도착 전에 플레이어가 `fill`을 내리거나 물린 비율 | 30~70% | 위협의 칸 수, 해법의 수 |
| F7 | 결과의 재사용 | 고른 대가, 흉터, 선언, 갈림의 선택 중 그 뒤에 평가된 조건(결말, 복잡화, 화제)이 읽는 이력 패턴(원고에서 정적으로 뽑음)에 든 비율 | 50% 이상 | 원고의 패턴과 결말 조건 |
| F8 | 관계의 변화 | 플레이마다 `regards`가 시작과 달라진 인물 수, 부탁의 약속이 지킴으로 끝난 비율 | 2명 이상, 40~80% | 인물의 욕망과 부탁 |
| F9 | 결말의 분산 | 같은 이야기 여러 플레이의 결말 분포의 엔트로피를 최대값으로 나눈 값 | 0.5 이상 | 갈림과 결말 조건 |
| F10 | 장의 길이 | 장마다 박자가 오른 단계 수, 마감으로 끝난 장의 비율 | 20~40단계, 50% 이하 | `B`, 마감의 칸 수 |
| F11 | 이탈 | 결말 전에 그만둔 게임의 비율과 그때의 장 | 장 1에서 20% 이하 | 첫 장의 길이와 첫 굴림까지의 단계 |
| F12 | 설문 | 결말 뒤 5점 척도: "내 선택이 이야기를 바꿨다", "다시 하고 싶다", "인물이 나를 기억했다" | 평균 4 이상 | 가장 낮은 문항의 요소(2절) |

## 6. 가설과 판단

- **H1**: 대가 있는 성공의 비율(F4)이 결과와 긴장의 주된 원천이다. F4가 범위 밖이면 F7, F12의 결과 문항도 떨어진다.
- **H2**: 문장이 버튼보다 조금 유리하고(engine 2.5의 추천 버튼) 잘 받아들여지면(F1) 플레이어가 문장을 쓴다(F2), 그리고 문장을 쓰는 플레이어가 주체성을 더 높게 답한다(F12).
- **H3**: 마감과 위협이 다가오는 것이 보이면 플레이어가 반응하고(F6), 마감으로 끝나는 장(F10)이 늘면 이탈(F11)이 는다.
- **H4**: 약속과 관계의 변화(F8)가 "인물이 나를 기억했다"(F12)를 가장 잘 설명한다.

판단의 절차:

1. 지표는 원고와 규칙을 고치기 전에 새로 모은 플레이로 잽니다. 고치는 데 쓴 플레이로 고친 결과를 재지 않습니다.
2. 한 번에 한 곳만 고치고, 고치기 전과 뒤를 같은 지표로 비교해 둘 다 보고합니다.
3. 한 지표를 맞추려다 다른 요소의 지표가 범위 밖으로 나가면 고치지 않습니다.
4. 가설이 지표로 거듭 반박되면 목표 범위가 아니라 가설을 고칩니다.

통과한 테스트와 맞춘 지표는 재미의 전제를 보여 줄 뿐이고, 재미 자체는 F12와 실제 플레이의 기록으로만 판단합니다.
