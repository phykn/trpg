# AI

**두 모델이 무엇을 받아 무엇을 돌려주는가**를 정한다. 무엇을 받고 무엇을 받지 않는지는 [data/03 3절](../data/03-state.md)이, 대답과 장면의 규칙은 [game/04](../game/04-talk.md)가 정한다. 이 문서는 그것을 모델에게 묻는 법을 정한다. engine 문서의 첫 문서이고, 나머지는 맨 끝의 "문서" 표에 있다.

## 한눈에

- 모델은 둘이다. **판단 모델**은 고르기만 하고, **서술 모델**은 말하기만 한다.
- 판에 닿는 것은 판단 모델이 고른 것뿐이다. 그것도 규칙이 내놓은 보기 가운데 하나다.
- 서술 모델의 글은 판단 모델이 검사한다. 떨어지면 두 번까지 다시 쓰게 한다.
- 두 모델 모두 이 저장소 밖에서 돈다. 서버는 켜질 때 설정의 모델이 도는지 확인하고, 다르면 켜지지 않는다.

| | 판단 모델 | 서술 모델 |
|---|---|---|
| 모델 | **카나나** `kakaocorp/kanana-2-v-decide-3b-2611` | **gemma4** `mlx-community/gemma-4-26B-A4B-it-qat-4bit` |
| 자리 | `:8081` | `:8082` |
| 설정 | `DECISION_MODEL=kanana` | `LLM_MODEL=gemma4` |
| 하는 일 | 알아듣기(1절), 글 검사(4절) | 대답(2절), 장면(3절) |
| 묻는 법 | `POST /v1/systemone`. 물음마다 확률을 돌려준다 | OpenAI 꼴의 채팅(`/v1/chat/completions`). 쓰이는 대로 흘려보낸다. 생각 모드는 늘 끈다(`enable_thinking: false`) |
| 켜질 때 확인 | `GET /v1/info`의 `run`이 위 이름으로 시작한다 | `GET /v1/models`에서 위 이름을 담은 모델이 `loaded`다. 이름의 `/`가 `--`로 바뀐 스냅숏 경로로도 온다 |

두 모델은 local-models가 띄운다. 이 저장소는 띄우지도 끄지도 않는다.

## 1. 알아듣기

묻기의 문장 하나를 [data/04 2절](../data/04-change.md)의 보기 가운데 하나로 바꾼다. 판단 모델에게는 아래 넷을 한 번에 보낸다.

| 물음 | 꼴 | 보기 |
|---|---|---|
| **무엇을 하려는가** | 고르기 | 상대에게 사건이나 다른 사람에 관해 묻는다, 다른 곳으로 간다, 인사나 날씨나 상대 자신에 관한 잡담이다 |
| **어느 화제를 묻는가** | 고르기 | 상대의 나온 화제마다 하나, 그리고 "어느 화제도 아니다" |
| **어디로 가려는가** | 고르기 | 갈 수 있는 곳 |
| **두 가지를 묻는가** | 예, 아니오 | 서로 다른 두 가지를 한꺼번에 묻는다 |

함께 보내는 상황 글에는 말하는 상대와 플레이어의 문장만 넣는다. 지금 곳을 넣으면 곳의 이름이 든 화제로 쏠렸다("사당 앞을 지나간 적 있니?"를 숲길에서 물으면 "숲길에서 본 것"). 두 가지를 묻는가의 물음은 화제가 둘 이상일 때만 보낸다.

화제의 보기에는 **화제의 이름**과 이야기가 적은 **묻는 말**을 함께 적는다. 묻는 말은 그 화제를 물을 때 쓸 법한 문장 한둘이다. 판단 모델만 보고, 플레이어에게는 보이지 않는다. 답을 담지 않는다([data/02](../data/02-story.md) 화제).

> 브람의 화제 "독미나리" — 보기의 글: `"독미나리"에 관해 묻는다. 예: 독미나리를 다루는 사람이 누구입니까? / 그 독초는 어디서 구합니까?`

**고르는 법**

위에서부터 처음 맞는 줄을 따른다. 확률은 판단 모델이 보기마다 돌려주는 값이다.

| 때 | 되는 것 |
|---|---|
| 무엇을 하려는가가 "다른 곳으로 간다" | 어디로 가려는가의 곳으로 옮기기 |
| 두 가지를 묻는가가 0.85 이상이고, 둘째 화제의 확률이 "어느 화제도 아니다"보다 높다 | **화제 둘**. 확률이 높은 두 화제를 묻는다 |
| 가장 높은 화제의 확률이 문턱 이상 | 그 화제를 묻는다. 무엇을 하려는가가 잡담이어도 그렇다 |
| 무엇을 하려는가가 잡담 | 잡담 |
| "어느 화제도 아니다"가 가장 높다 | 넘김(답할 것이 없다) |
| 그 밖 | **확실하지 않다**. 확률이 높은 두 화제의 이름으로 되묻는다 |

- 문턱은 0.75다. 판단 모델의 `confidence`는 가장 높은 확률과 다른 값이라 쓰지 않는다.
- 화제의 확률이 문턱을 넘으면 무엇을 하려는가보다 화제를 믿는다. 시험에서 화제를 묻는 문장의 무엇을 하려는가가 잡담으로 나온 일이 많았는데, 화제가 0.8을 넘은 문장은 늘 맞았고, 잡담 문장의 화제는 0.65를 넘지 않았다.
- 두 가지를 묻는가는 화제 둘을 묻는 문장에서 0.9 남짓, 그 밖에서 0.7 아래였다. 두 화제의 확률로는 가르지 못했다. 둘을 묻는 문장도 한 화제에 0.9를 넘게 주곤 했다.
- 상대가 없으면 무엇을 하려는가의 보기는 "다른 곳으로 간다"와 "이곳에 머물며 둘러보거나 혼잣말을 한다"뿐이고, 화제의 물음을 보내지 않는다. 옮기기가 아니면 둘러보기다.

**남기는 것**

- 고른 보기와 물음마다의 확률을 기록의 "알아들은 것"에 남긴다([data/05](../data/05-save.md)). 확률은 시험과 문턱 고치기에 쓴다.
- 판단 모델이 답하지 않으면 그 한 마디를 처리하지 않는다. 판은 그대로이고, 화면은 같은 영수증으로 다시 보낸다.

## 2. 대답

사람의 대답이다. 서술 모델이 받는 것은 [game/04 3절](../game/04-talk.md)의 넷뿐이다.

| 받는 것 | 모양 |
|---|---|
| **신상** | 이야기의 글 그대로 |
| **할 말** | 이번에 말할 것. 아래 표 |
| **태도** | 낱말로 준다. "믿음 낮음, 두려움 보통" |
| **플레이어의 문장** | 방금 쓴 문장. 내밀기와 걸기면 곁들인 말 |

| 할 말의 종류 | 서술 모델에게 주는 것 |
|---|---|
| 참말, 거짓말, 깨진 뒤, 풀린 뒤 | 그 글. 거짓말인지는 알리지 않는다 |
| 꺼림 | "이 화제는 말해 주지 않는다" |
| 넘김 | "답할 것이 없다" |
| 운 떼기 | 그 화제의 이름 |
| 다 말했다 | "더 말할 것이 없다" |
| 되묻기 | 헷갈리는 화제들의 이름 |
| 잡담 | 없다 |
| 화제 둘 | 둘의 글을 차례로. 각각 짧게 |
| 걸기의 결과 | 들은 말에 걸었으면 그 말을 짧게 되풀이하라는 것(game/05 3절) |

**지키게 하는 것**

- 한두 문장. 그 사람의 말투로.
- 할 말의 뜻을 바꾸지 않는다. 할 말에 없는 사람, 물건, 때, 곳을 더하지 않는다.
- 꺼림과 넘김에서는 내용을 한 마디도 말하지 않는다.

## 3. 장면

곳과 일을 들려준다. 받는 것은 [game/04 6절](../game/04-talk.md)대로다.

| 받는 것 | 모양 |
|---|---|
| **곳의 모습** | 처음 들어설 때만. 다시 들어서면 곳의 이름만 |
| **이번에 적힌 줄** | 볼 것의 글, 물건의 이름 |
| **일어난 일** | 조짐, 번진 일, 열리지 않은 잠김, 결말의 대목, 진실 풀이 가운데 이번 것 |
| **이곳의 사람** | 이름. 장면 끝에 알린다 |

- 두세 문장, "당신"과 합니다체(game/07 6절).
- 지어내는 것은 날씨, 소리, 빛 같은 분위기뿐이다. 받은 줄에 없는 물건이나 흔적은 그리지 않는다.

**DM**도 같은 모델이 진행자의 목소리로 쓴다. 언제 말하는지는 규칙이 정한다(game/07 2절).

| 받는 것 | 모양 |
|---|---|
| **상황** | 판의 시작, 처음 만난 사람, 입을 다문 사람, 오래 새 줄이 없음, 칸이 다 됨 가운데 하나 |
| **인물** | 있으면 이름, 신상, 플레이어를 대하는 태도 |
| **가 보지 않은 곳** | 권할 곳이 있으면 이름 |
| **권할 일** | 진행자가 플레이어에게 건넬 권유 |

- 한두 문장, "당신"과 합니다체. 인상은 신상과 태도에서만 짐작하고, 사건의 진실과 단서, 화면 조작은 말하지 않는다.
- 글 검사는 장면과 같다(4절).

## 4. 글 검사

서술 모델이 쓴 대답과 장면을 판단 모델이 예, 아니오로 검사한다.

| 검사 | 떨어지는 때 |
|---|---|
| **뜻** | 할 말이 있는데 그 뜻이 글에 없거나 바뀌었다 |
| **더한 것** | 할 말이나 받은 줄에 없는 사람, 물건, 때, 곳이 나온다 |
| **새는 것** | 꺼림, 넘김, 운 떼기, 되묻기에서 화제의 내용을 말했다 |
| **길이** | 대답이 세 문장, 장면이 네 문장, 결말이 여덟 문장을 넘는다. 문장 끝의 문장부호로 셈하며 모델에게 묻지 않는다. 결말은 진실 풀이를 담으므로 길다 |
| **지시문** | 글이 "할 말", "지침", "신상"처럼 프롬프트의 낱말을 쓴다. 모델에게 묻지 않는다 |
| **말투** | 장면, 결말, DM의 글이 따옴표 밖에서 "-세요", "-어요", "-군요" 같은 해요체로 끝난다. 인물의 대답은 제 말투를 따르므로 보지 않는다. 모델에게 묻지 않는다 |

- 뜻과 새는 것은 "그렇다"의 확률이 0.5 이상, 더한 것은 "아니다"의 확률이 0.15 이상이어야 통과한다. 새는 것은 "쓴 글이 사건에 관한 내용을 알려 주지 않는가"로 묻는다.
- 이 문턱은 2026-11-15의 글 시험(5절)으로 정했다. 처음 값(뜻 0.75, 더한 것 0.7)으로는 첫 글 29개 가운데 20개가 떨어졌는데, 거의 다 바른 글이었다. 바른 글의 더한 것은 0.1에서 0.9까지 퍼졌고, 내용을 잃거나 뜻을 바꾼 글에도 뜻이 0.84~0.93으로 나왔다. 카나나의 검사는 바른 글과 틀린 글을 가르지 못하므로, 문턱은 뚜렷한 때에만 다시 쓰게 낮게 둔다. 내용을 잃는 글은 검사가 아니라 대답의 프롬프트로 막는다("할 말이 있으면 그 내용을 빠짐없이 말한다. 태도는 말투에만 드러낸다").
- 떨어지면 떨어진 까닭을 붙여 다시 쓰게 한다. **두 번까지.**
- 두 번 다시 써도 떨어지면 마지막 글을 쓴다. 수첩이 믿을 수 있는 기록이므로 글 하나가 틀려도 추리는 흐려지지 않는다(game/01). 떨어진 것은 기록에 남겨 시험에서 본다.
- 검사 결과는 기록의 그 턴의 글에 함께 남긴다. 판 상태에는 닿지 않는다.
- 흘려보낸 글이 검사에 떨어지면 화면의 글을 다시 쓴 글로 바꾼다. 대답이 끝날 때까지 입력은 잠겨 있다(game/07 2절).

## 5. 시험

모델을 바꾸거나 문턱, 물음, 할 말을 고칠 때 돌린다. 모델이 떠 있어야 한다.

- **알아듣기.** 이야기 폴더의 `evals.yaml`에 묻는 자리(`사람 X`는 그 사람에게, `곳 X`는 상대 없이)마다 기대하는 보기(화제, `A + B`, 잡담, 넘김, `곳 X`)와 문장들을 적는다. 수첩에는 이야기의 줄이 모두 적혀 있다고 친다. 보기가 가장 많은 때다. 맞힘, 되물음, 모자람(화제 둘 가운데 하나만), 틀림, 틀린 화제를 센다. 틀린 화제가 가장 나쁘다. 되묻기는 대화를 한 번 늦출 뿐이지만, 틀린 화제는 묻지 않은 말을 수첩에 적는다. 맞힘 85% 이상, 틀린 화제 2% 이하면 통과다.
- **글.** 이야기의 할 말마다 대답을 쓰게 하고 4절의 검사를 돌린다. 떨어진 몫과 다시 쓴 횟수를 본다.

**글 시험의 결과.** 2026-11-15, `dawn`의 할 말 24개와 장면 5개에서 첫 글이 떨어진 것은 2개, 다시 쓴 횟수는 모두 3번, 두 번 다시 써도 떨어진 것은 1개였다. 기록은 `qa_test/runs/text-dawn-3/`에 있다. 검사가 놓친 틀린 글이 하나 있다(qa/findings.md).

**알아듣기 시험의 결과.** 2026-11-15, `dawn`의 64문장에서 맞힘 57(89%), 되물음 2, 넘김과 잡담을 바꾼 것을 포함해 틀림 5, 틀린 화제 0이었다. `skeleton`의 10문장은 맞힘 8이었다. 기록은 `qa_test/runs/evals-dawn-5/`와 `evals-skeleton-5/`에 있다. 남은 틀림은 이야기를 알아야 잇는 말이다("촌장님"이 마렌의 아버지라는 것, "수레"가 집안일이라는 것). 이것은 화제의 묻는 말로 고친다.

## 6. 미리 보기

2026-11-15에 첫 이야기의 브람과 토빈에게 하는 문장 14개로 카나나를 시험했다. 기록은 `qa_test/runs/kanana-probe-1/`에 있다.

| 묻는 법 | 맞힘 | 틀림의 모양 |
|---|---|---|
| 무엇을 하려는가 + 화제마다 예, 아니오 | 8 / 14 | 화제를 바꿔 말하면 놓친다("독초" → 독미나리). 이름이 넓은 화제가 다른 물음에도 예라고 한다 |
| 모든 보기를 한 고르기에 | 10 / 14 | 잡담을 화제로 고른다("몇 살이니?") |
| **무엇을 하려는가 + 어느 화제(고르기) + 어디로** | **13 / 14** | 화제 둘을 한 문장에 물으면 확실하지 않다로 빠진다. 틀린 화제를 고른 것은 없다 |

- 1절은 셋째 묻는 법이다. 한 번에 0.3초 안팎이 걸렸다. 서버가 켜진 뒤 첫 물음만 1초 남짓이다.
- 글 검사(4절)는 할 말 하나에 글 셋으로만 보았다. 바른 글은 뜻 0.81, 더한 것 0.14였다. 뜻을 바꾼 글은 뜻 0.65, 없는 사람을 더한 글은 더한 것 0.45였다. 0.5로는 가르지 못해 문턱을 높였다.
- gemma4는 브람의 깨진 뒤 말을 "~소" 말투로 뜻을 지켜 썼다. 서버가 켜진 뒤 첫 글은 1분 넘게 걸렸고, 그 뒤로는 1초 남짓이었다. 서버가 켜질 때 짧은 글을 한 번 쓰게 해 데워 둔다.

**아직 볼 것**

- 글 검사의 문턱(4절)을 5절의 시험으로 정한다.
