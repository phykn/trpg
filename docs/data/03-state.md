# 판

**한 판에서 바뀌는 것**을 정한다. 판은 이야기 하나를 처음부터 끝까지 하는 한 번이다. 낱말은 [game/03](../game/03-notebook.md)을 따른다.

## 한눈에

- 판은 **이야기 + 판 상태**다. 이야기는 바뀌지 않고, 판 상태만 바뀐다.
- 판 상태에는 **셈해서 얻을 수 없는 것만** 둔다. 셈해서 얻을 수 있는 것은 그때그때 셈한다(2절).
- 누가 무엇을 받는지는 정해져 있다(3절). 플레이어도 AI도 판 상태 전부를 받지 않는다.

## 1. 판 상태

묶음은 [01 3절](01-ontology.md)을 따른다. 바탕은 판 전체에 하나씩 있는 것이다.

| 묶음 | 무엇 | 모양 | 처음 |
|---|---|---|---|
| **바탕** | **씨앗** | 수 하나. 주사위가 여기서 나온다 | 판을 열 때 정한다 |
| | **턴** | 수. 한 마디마다 하나 는다 | 0 |
| | **능력치** | 매력, 완력, 재치, 솜씨마다 0, +1, +2. +2와 +1은 하나씩 | 없다. 첫 행동으로 고른다(04 2절) |
| **알아낸 것** | **수첩** | 줄 주소(02 4절)와 적힌 턴의 목록. 적힌 차례대로 | 시작하는 곳에 들어서며 적힌 줄 |
| | **그은 줄** | 말 주소 모음 | 없다 |
| | **말을 아낀다** | 꺼림 주소 모음 | 없다 |
| | **실마리** | 꺼림, 잠김 주소 모음 | 없다 |
| | **가려 낸 말** | 말 주소마다 "숨기는 것이 있다"나 "거짓이 아니다" | 없다 |
| | **읽은 줄** | 줄 주소 모음. 수첩에서 한 번 본 줄 | 없다 |
| **사람과의 사이** | **열린 막힘** | 막힘 주소 모음 | 없다 |
| | **태도** | 사람마다 믿음과 두려움. 각각 -1, 0, +1 | 이야기의 처음 태도 |
| | **닫힌 방식** | 겨눈 것의 주소와 방식의 짝 모음 | 없다 |
| | **대화 셈** | 사람마다 화제별로 물은 횟수, 연달아 넘긴 횟수 | 0 |
| | **말하는 상대** | 사람의 이름이나 없음 | 시작하는 곳에 사람이 하나면 그 사람 |
| **흐른 것** | **쓴 칸** | 0부터 칸 수까지 | 0 |
| | **지금 곳** | 곳의 이름 | 시작하는 곳 |
| | **가 본 곳** | 곳의 이름 모음 | 시작하는 곳 |
| **번진 것** | **번진 일** | 번진 일마다 "벌어졌다"나 "막았다". 아직 정해지지 않은 일은 들어 있지 않다 | 없다 |
| | **사람의 곳** | 사람마다 곳의 이름 | 이야기의 있는 곳 |
| | **떠난 사람** | 사람의 이름 모음 | 없다 |
| | **없어진 것** | 볼 것의 이름 모음 | 없다 |
| **결론** | **결론** | 누가: 사람 이름. 어떻게, 왜: 줄 주소. 각각 비울 수 있다 | 내지 않았다 |

- **수첩의 줄은 주소만 둔다.** 글은 이야기에 있다. 판 상태에 글을 베껴 두지 않는다.
- **연달아 넘긴 횟수**는 그 사람이 넘기지 않고 대답하면 0으로 돌아간다. 통하지 않은 내밀기도 넘김으로 센다(game/04 5절).
- **결론은 낸 뒤로 바뀌지 않는다.** 결론이 있으면 판은 끝난 것이다.

## 2. 셈해서 얻는 것

판 상태에 두지 않는다. 판 상태와 이야기만 있으면 언제든 같은 답이 나온다.

| 무엇 | 셈하는 법 |
|---|---|
| **나온 것** | 나오는 조건이 없거나, 그 조건의 줄이 수첩에 있는 곳, 볼 것, 화제. 잠긴 것 안에 든 것은 그 잠김이 열린 막힘에 있어야 한다. 없어진 것과 떠난 사람의 화제는 빠진다 |
| **이곳의 사람** | 사람의 곳이 지금 곳이고, 떠나지 않은 사람 |
| **갈 수 있는 곳** | 나온 곳 가운데 지금 곳에서 이어진 곳. 이어지지 않은 곳은 가장 짧은 길과 그 칸 수 |
| **표시** | 안 가 봄: 수첩에 곳 줄이 있고 가 본 곳에 없다. 열었다: 그 잠김이 열린 막힘에 있다. 떠났다: 떠난 사람에 있다. 실마리: 실마리에 있고 그 막힘이 아직 열리지 않았다. 나머지 표시는 판 상태 그대로다 |
| **새 줄** | 수첩에 있고 읽은 줄에 없는 줄 |
| **시각과 남은 칸** | 시작 시각 + 쓴 칸 × 한 칸의 분. 칸 수 - 쓴 칸 |
| **화제의 지금 자세** | 그 화제의 거짓말이나 꺼림이 열린 막힘에 있으면 "숨기지 않는다"다. 아니면 이야기의 자세 그대로다 |
| **맞닿는가** | 내민 단서의 보여 주는 사실이나 성질이 막힘이 바라는 것과 같은가(game/05 1절). 자기 말을 자기 꺼림에 내민 것, 거짓말 갈래의 말, 아직 나오지 않은 화제의 막힘은 빼고 견준다(game/05 2절) |
| **성공률** | 2d6 + 능력치 + 방식에 따른 태도(또는 단단함)가 8 이상일 몫(game/05 3절) |
| **결말** | 결론과 진실을 견준 밝힌 정도, 그리고 번진 일의 결과(game/06 4절) |

- 수첩에 줄이 하나 적히면 나온 것이 늘 수 있다. 늘어난 것이 지금 곳에 있으면 그 자리에서 다시 적는다. 더 늘지 않을 때까지 되풀이한다(04 2절).

## 3. 누가 무엇을 받는가

판 상태 전부를 받는 것은 규칙뿐이다. 나머지는 아래만 받는다.

| 받는 쪽 | 받는 것 | 받지 않는 것 |
|---|---|---|
| **화면** | 수첩의 줄과 표시, 새 줄, 지금 곳, 이곳의 사람, 말하는 상대, 시각과 남은 칸, 갈 수 있는 곳과 칸, 줄에서 할 일의 단추와 성공률, 대화, 결론. 결말 뒤에는 결말, 맞힌 물음, 진실 풀이, 놓친 것 | 보여 주는 사실, 성질, 막힘의 종류와 바라는 것, 태도의 값, 나오지 않은 것. 결말 전의 진실 |
| **알아듣는 AI** | 플레이어의 문장, 규칙이 만든 보기의 이름(04 2절): 무엇을 하려는가(묻기, 옮기기, 잡담), 말하는 상대의 나온 화제와 "어느 화제도 아니다", 갈 수 있는 곳(engine/01 1절) | 자세, 할 말, 그 밖의 모든 것 |
| **말하는 AI** | 신상, 이번에 할 말, 태도, 플레이어의 문장(game/04 3절) | 참인지 거짓말인지, 숨기는 것, 다른 사람의 것, 진실 |
| **장면을 그리는 AI** | 곳의 모습, 이번에 적힌 줄, 일어난 일, 이곳의 사람의 이름(game/04 6절) | 나오지 않은 것, 보여 주는 사실, 진실. 진실 풀이는 결말에서만 받는다 |

- 화면은 받은 것을 그대로 쓴다. 성공률이나 갈 수 있는 곳을 화면이 따로 셈하지 않는다.
- AI가 돌려준 것 가운데 판에 닿는 것은 **알아들은 것**뿐이다. 그것도 규칙이 내놓은 보기 가운데 하나여야 한다(04 2절).
