# 지키는 것과 저장

**언제나 참이어야 하는 것**과 **판을 어떻게 저장하고 다시 여는가**를 정한다.

## 한눈에

- 바뀐 것을 쓸 때마다 1절의 지키는 것을 본다. 하나라도 어긋나면 규칙의 잘못이다. 그 한 마디를 버리고 잘못으로 알린다.
- 저장하는 것은 **기록**이다. 판 상태는 기록의 바뀐 것을 처음부터 차례로 써서 만든다.
- 판은 시작할 때의 **이야기 사본**을 함께 지닌다. 이야기 파일을 고쳐도 하던 판은 그대로 이어진다.
- 같은 요청이 두 번 와도 **한 번만** 처리한다.

## 1. 지키는 것

**수첩**

- 수첩의 줄은 이야기에 있는 주소이고, 같은 줄은 한 번만 있다.
- 수첩의 줄은 빠지지 않는다. 그은 줄도 수첩에 남는다.
- 적히는 줄은 적히는 그때 나와 있다.
- 그은 줄은 깨진 거짓말의 거짓말 갈래다. 들은 거짓말이 깨졌으면 그 말은 그어져 있다.
- 깨진 뒤와 풀린 뒤의 말은 그 막힘이 열린 뒤에만 수첩에 있다.

**막힘과 표시**

- 열린 막힘은 다시 닫히지 않는다.
- 떠난 사람의 막힘은 떠난 뒤에 열리지 않는다.
- 말을 아낀다가 붙은 꺼림은 열리지 않은 것이다.
- 실마리는 그 꺼림이나 잠김에 걸었다가 실패한 뒤에만 붙는다.
- 가려 낸 말은 수첩에 있는 들은 말이다. 가려 낸 뒤에 깨져 그어질 수는 있다.
- 같은 것에 같은 방식으로 두 번 걸지 않는다.

**사람과 곳**

- 능력치는 +2가 하나, +1이 하나, 나머지는 0이다.
- 태도는 믿음과 두려움 모두 -1, 0, +1 가운데 하나다.
- 지금 곳은 나온 곳이고, 가 본 곳에 있다.
- 말하는 상대는 이곳의 사람이거나 없음이다. 떠난 사람은 아니다.

**시간과 끝**

- 쓴 칸은 0부터 칸 수까지이고, 줄지 않는다.
- 정해진 번진 일은 그 때가 온 것뿐이고, 한 번 정해지면 바뀌지 않는다.
- 쓴 칸이 칸 수에 닿은 뒤로는 수첩 읽기와 결론 내기만 있다.
- 결론의 누가는 수첩의 사람 줄이고, 어떻게와 왜는 수첩의 단서 줄이다. 비울 수 있다.
- 결론은 한 번만 있다. 결론이 있으면 그 뒤로 바뀐 것이 없다.

**만들기**

- 판 상태는 기록의 바뀐 것을 처음부터 차례로 쓴 것과 같다.
- 바뀐 것은 모두 규칙이 냈다. 기록에서 AI의 글을 모두 지워도 판 상태는 같다.

## 2. 저장 파일

판 하나에 JSON 파일 하나다. `saves/<판의 이름>.json`에 둔다.

| 무엇 | 담는 것 |
|---|---|
| **머리** | 판의 이름, 형식 판본, 이야기의 이름과 판본 표지(02 6절), 씨앗, 만든 때 |
| **이야기 사본** | 판을 시작할 때의 굳힌 이야기 |
| **기록** | 턴마다 아래 표 |
| **마지막 판 상태** | 빨리 열려고 함께 둔다. 기록에서 다시 만들 수 있다 |

- **판의 이름**은 서버가 판을 열 때 만든다. 다른 판과 겹치지 않는다.

기록의 한 턴:

| 무엇 | 담는 것 |
|---|---|
| 턴 | 수 |
| 영수증 | 요청에 붙어 온 것 |
| 행동 | 04 2절의 행동 하나 |
| 알아들은 것 | 묻기였으면 AI가 고른 보기 |
| 주사위의 눈 | 굴렸으면 두 눈 |
| 바뀐 것 | 04 1절의 목록 |
| 일어난 일 | 조짐, 번진 일 |
| 글 | AI가 쓴 대답과 장면, 그 글 검사의 결과(engine/01 4절). 화면에 다시 보여 주는 데와 시험에만 쓴다 |

- **한 마디마다 쓴다.** 기록에 한 턴을 더하면 파일을 쓴다. 글이 나중에 오면 그 턴에 덧붙여 다시 쓴다.
- **한꺼번에 쓴다.** 새 파일을 다 쓴 뒤에 옛 파일과 바꾼다. 쓰다 멈춰도 옛 파일은 온전하다.
- **글은 판이 아니다.** 글이 없거나 망가져도 판은 같다. 글이 없는 턴은 다시 열 때 글만 다시 쓰게 한다.

## 3. 다시 열기

1. 저장 파일을 읽는다. 형식 판본이 지금보다 옛것이면 지금 형식으로 옮긴다(4절).
2. 이야기 사본과 씨앗으로 처음 판 상태를 만든다.
3. 기록의 턴마다 **바뀐 것을 차례로 쓴다.** 규칙도 AI도 다시 부르지 않는다. 쓸 때마다 1절의 지키는 것을 본다.
4. 어긋나는 것이 있으면 그 판은 망가진 것이다. 열지 않고 알린다. 지우지 않는다.
5. 마지막 판 상태가 있으면 다시 만든 것과 견준다. 다르면 다시 만든 것을 믿는다.

- **규칙을 다시 돌리지 않는 까닭.** 규칙은 고쳐질 수 있다. 다시 열 때 규칙을 돌리면, 규칙을 고칠 때마다 하던 판이 다른 판이 된다. 기록의 바뀐 것은 그때의 규칙이 낸 결과이므로 그대로 쓴다.
- **시험에는 규칙을 다시 돌린다.** 기록의 행동과 알아들은 것을 지금의 규칙에 넣어, 같은 바뀐 것과 같은 주사위의 눈이 나오는지 본다. 다르면 규칙이 바뀐 것이다. 버그를 되살릴 때도 기록만 있으면 된다.
- 화면은 판의 이름만 기억한다. 다시 열기에 실패해도 그 이름을 지우지 않는다(game/07 5절).

## 4. 판본

| 판본 | 무엇이 바뀌면 | 하는 일 |
|---|---|---|
| **형식 판본** | 저장 파일, 행동, 바뀐 것의 모양 | 올린다. 옛 판을 새 형식으로 옮기는 길을 함께 둔다 |
| **이야기 판본 표지** | 이야기의 내용. 글자 하나라도 | 저절로 바뀐다. 하던 판은 자기 사본으로 이어진다 |

- 옮기는 길이 없는 옛 형식의 판은 열지 않고, 지우지도 않는다.
- **옛 엔진의 판은 읽지 않는다.** 옛 엔진([docs/old](../old/))은 없앨 것이고 참고로만 남긴다. 새 게임의 형식 판본은 1부터 센다.

## 5. 영수증

- 화면은 한 마디마다 판 안에서 겹치지 않는 영수증을 붙인다. 답이 오지 않으면 **같은 영수증으로 같은 한 마디**를 다시 보낸다(game/07 5절).
- 같은 영수증이 기록에 있으면 처리하지 않고 기록의 결과를 돌려준다. 글이 없으면 글만 다시 쓰게 한다.
- 같은 영수증으로 다른 한 마디가 오면 받지 않는다.
- 받지 않은 행동(04 2절)은 기록에 남지 않으므로 영수증도 쓰이지 않는다.
