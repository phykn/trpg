# 이야기

**이야기 파일에 무엇이 어떤 모양으로 들어 있는가**를 정한다. 무엇을 적는지와 어떻게 검사하는지는 [game/08](../game/08-story.md)이 정하고, 이 문서는 그것을 데이터로 적는 모양을 정한다. 보기는 [game/10](../game/10-first-story.md)의 이야기다.

## 한눈에

- 이야기는 `scenarios/<폴더>/` 안의 **파일 하나**(`story.yaml`, UTF-8)다. 판이 시작되면 바뀌지 않는다. 같은 폴더의 `evals.yaml`과 `evals-held.yaml`은 알아듣기 시험의 자료이고 이야기가 아니다(engine/01 5절).
- 모든 것은 **이름**으로 서로를 가리킨다. 이름은 이야기 안에서 하나뿐이다.
- 수첩의 줄, 막힘, 나오는 조건은 모두 **주소**로 가리킨다(4절). 주소가 가리키는 것이 없으면 이야기는 시작되지 않는다.
- 게임은 이름의 뜻을 모른다. 이름은 가리키는 데만 쓴다.

## 1. 묶음

| 묶음 | 하나하나가 무엇인가 |
|---|---|
| **머리** | 제목, 도입, 시작하는 곳, 시간, 진실. 이야기에 하나 |
| **사실** | 사건에 관한 참인 문장 하나 |
| **성질** | 물건의 특징 하나 |
| **곳** | 갈 수 있는 곳 하나 |
| **볼 것** | 곳에 놓인 것 하나. 본 것이나 물건으로 수첩에 적힌다 |
| **사람** | 인물 하나. 화제를 품는다 |
| **번진 일** | 정해진 칸에 벌어지는 일 하나 |
| **결말** | 밝힌 정도 넷의 대목과 진실 풀이 |

- **묶음의 열쇠가 곧 이름이다.** 사실, 곳, 볼 것, 사람의 이름은 따로 적지 않고 묶음 안의 열쇠로 쓴다.
- **이름은 묶음을 넘어 하나뿐이다.** "안에 든 것"(볼 것이나 곳)과 "알리는 것"(곳이나 사람)처럼 묶음이 섞인 자리에서도 무엇을 가리키는지 하나로 정해져야 하기 때문이다. 같은 이름이 두 번 나오면 이야기는 시작되지 않는다. 화제의 이름만은 그 사람 안에서 하나뿐이면 된다.
- 이름에는 `.`을 쓰지 않는다. 주소의 가름표다(4절).
- **알리는 것**: 줄의 글에 다른 곳이나 사람이 나오면 그 이름을 따로 적는다. 그 줄이 적힐 때 그 곳과 사람의 줄도 적힌다(game/03 1절). 게임은 글을 읽어 이름을 찾지 않는다. *브람의 깨진 뒤 말은 촌장 집과 고드릭을 알린다.*
- **화면에 나오는 이름**은 따로 적을 수 있다. 적지 않으면 이름이 그대로 나온다.
- 수첩과 화면에는 이야기의 글이 적힌 그대로 나온다. 사람의 말만 AI가 그 사람의 말투로 바꿔 들려준다(game/04). 수첩에 적히는 글은 해라체다(game/07).

## 2. 묶음마다 적는 것

"꼭"이 아닌 것은 없어도 된다.

| 적는 것 | 모양 | |
|---|---|---|
| 이름 | 영문 짧은 이름. 저장 파일이 이 이름으로 이야기를 찾는다 | 꼭 |
| 제목 | 글 | 꼭 |
| 도입 | 글 | 꼭 |
| 시작하는 곳 | 곳의 이름 | 꼭 |

> 시각 — 시작: 20:00 · 한 칸: 20분 · 칸 수: 24

잠김:

| 적는 것 | 모양 | |
|---|---|---|

- 안에 든 것은 열린 뒤에야 나온다. 나오는 조건이 "열었다"인 것과 같다.
- 안에 든 것이 곳이면 그 곳이 어디와 이어지는지는 그 곳에 적는다. *벽장 속 비밀 통로.*
- 잠긴 볼 것에도 줄이 있다. 잠긴 모습이 본 것으로 적힌다. *장부 궤짝이 잠겨 있었다.*
- 잠긴 볼 것도 물건이 아니다. 들고 다닐 수 없다.

## 3. 말

들은 말 한 줄은 화제 하나의 **갈래** 하나다. 갈래는 자세가 정한다.

| 자세 | 갈래 | 언제 말하는가 |
|---|---|---|
| 숨기지 않는다 | 참말 | 물으면 |
| 꺼린다 | 풀린 뒤 | 꺼림이 풀리면 |
| 거짓말한다 | 거짓말 | 깨지기 전에 물으면 |
| | 깨진 뒤 | 거짓말이 깨지면 |

- **거짓말 갈래는 아무것도 보여 주지 않는다.** 보여 주는 사실을 적을 자리가 없다.
- 꺼린다의 "말을 아낀다"는 말이 아니라 표시다(game/03). 갈래가 없다.

## 4. 주소

수첩의 줄, 막힘, 나오는 조건은 아래 주소로 가리킨다.

| 주소 | 가리키는 것 | 보기 |
|---|---|---|
| **곳** 이름 | 곳 줄 | 곳 여관 물레방아 |
| **사람** 이름 | 사람 줄 | 사람 토빈 |
| **볼 것** 이름 | 본 것 줄이나 물건 줄 | 볼 것 여관 나무패 |
| **말** 사람.화제.갈래 | 들은 말 줄 | 말 브람.징수관.깨진 뒤 |
| **거짓말** 사람.화제 | 거짓말 막힘 | 거짓말 브람.징수관 |
| **꺼림** 사람.화제 | 꺼림 막힘 | 꺼림 토빈.숲길에서 본 것 |
| **잠김** 볼 것 이름 | 잠김 막힘 | 잠김 장부 궤짝 |

- **나오는 조건은 줄 주소 하나다.** 그 줄이 수첩에 있으면 나온다. 거짓말 갈래의 말 주소는 쓰지 못한다(game/08 3절).
- **막는 조건은 막힘 주소 하나다.** 그 막힘이 열렸으면 막는다.

## 5. 무엇이 무엇을 가리키는가

검사 "가리키는 것이 있다"(game/08 6절)는 이 표의 화살표를 모두 따라가 본다.

| 무엇이 | 무엇을 |
|---|---|
| 머리 | 시작하는 곳 → 곳. 누가 → 사람. 어떻게, 왜 → 사실 |
| 곳 | 이어진 곳 → 곳. 나오는 조건 → 줄 |
| 볼 것 | 곳 → 곳. 성질 → 성질. 보여 주는 사실 → 사실. 알리는 것 → 곳, 사람. 나오는 조건 → 줄 |
| 잠김 | 약점 → 성질. 주인 → 사람. 안에 든 것 → 볼 것, 곳 |
| 사람 | 있는 곳 → 곳 |
| 화제 | 알리는 것 → 곳, 사람. 보여 주는 사실, 깨는 사실 → 사실. 바라는 것 → 사실, 성질. 나오는 조건 → 줄 |
| 번진 일 | 일 → 사람, 곳, 볼 것. 막는 조건 → 막힘 |

## 6. 읽어 들이기

서버가 켜질 때 이야기마다 이렇게 한다.

1. **읽는다.** 파일의 모양이 이 문서와 맞는지 본다.
2. **검사한다.** game/08 6절의 검사를 모두 한다. 셈하는 법은 [engine/03](../engine/03-check.md)이 정한다. 하나라도 떨어지면 서버는 켜지지 않는다. 알려 주기만 하는 것은 알리고 넘어간다.
3. **굳힌다.** 주소를 모두 풀어 두고, 사실마다 그것을 보여 주는 줄, 성질마다 그것을 가진 물건을 거꾸로 찾아 둔다. 규칙은 굳힌 이야기만 읽는다.
4. **판본을 매긴다.** 굳힌 이야기의 내용으로 판본 표지를 만든다. 글자 하나만 바뀌어도 표지가 바뀐다(05).
